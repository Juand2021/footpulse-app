# FootPulse · app web

App web visual (solo celular) del proyecto FootPulse, EPI Grupo 3, Universidad de Bogotá Jorge Tadeo Lozano.
Tres apartados: Proyecto (animación piezoeléctrica ligada al scroll), Cotizar e Invertir.

- `npm install` y `npm run dev` para trabajar en local.
- `npm run build` genera `dist/` (Vercel lo hace solo con cada push a `main`).
- Todas las cifras están en `src/data.js` y vienen del informe final del proyecto.
